# Сайт «Своё решение» — программа Евгения Дымы

Простой статический сайт: HTML + CSS + JS, без баз данных и без серверной части. Открывается и работает в любом браузере.

## Структура проекта

- `index.html` — главная (и единственная) страница сайта
- `css/styles.css` — все стили
- `js/main.js` — интерактивность (меню, раскрывающиеся блоки, увеличение сертификатов)
- `assets/img/` — все фотографии, сертификаты и иконка сайта

## Как разместить на хостинге

Загрузить содержимое этой папки целиком в корень сайта (или в нужную поддиректорию) на любом хостинге, который отдаёт статические файлы — Vercel, Netlify, GitHub Pages, обычный shared-хостинг с FTP и т.п. Отдельная настройка сервера, базы данных или переменные окружения не требуются.

## Проверить перед публикацией

- домен подключён по HTTPS;
- все ссылки в футере и кнопках ведут на актуальные Telegram/Instagram/YouTube/TikTok/Facebook аккаунты;
- сертификат «Past Life Regression Practitioner» и подпись под ним устраивают Евгения (уже подтверждено).
